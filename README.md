# Apna Bazaar UI Preview (not the production app)

This is a lightweight Android WebView shell for previewing a sample Apna Bazaar interface.
It does NOT connect to Firebase, authenticate users, place real orders, or process payments.
Sample shop, prices, and products are demonstration content only.

## Build a debug APK with GitHub Actions
1. Create a new GitHub repository.
2. Upload the contents of this folder (the files inside, not the enclosing folder).
3. Open the repository's Actions tab.
4. Select "Build Apna Bazaar UI Preview APK".
5. Press "Run workflow" (or push to main).
6. Open the completed run, download the `ApnaBazaar-UI-Preview-APK` artifact.
7. Extract the artifact ZIP and install `app-debug.apk` on your Android phone.

Package: in.apnabazaar.preview
Minimum Android: 7.0 (API 24)

This is a preview shell, not a reconstruction of all original source code.
